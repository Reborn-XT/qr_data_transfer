🛡️ Why Air-Gapped Optical Transfer?

Standard file-sharing relies on local networks, Bluetooth, internet cloud servers, or USB flash drives. In high-security settings, college labs, or network-restricted sites, these methods introduce vulnerabilities or are physically blocked.

⚡ Key Engineering Highlights

  • BadUSB Immunity: Data travels strictly through optical photons (light). No electrical contacts or device drivers are touched.
  • Zero Network Footprint: Operates 100% offline inside browser memory. 0 HTTP requests, 0 sockets, 0 backend dependencies.
  • In-Memory Gzip Compression: Uses Pako.js (Level 9 Deflate) to shrink file payloads up to 80% before QR serialization.
  • WASM Speed: Scans and decodes QR matrices using WebAssembly (zbar-wasm) at 20–30 FPS.
  • Out-of-Order Reassembly: Receives chunks in any random order, tracks missing pieces, and decompresses the full file automatically.
